# Mi portafolio personal

## Descripción

Este proyecto es mi portafolio personal,
desarrollado como parte de mi formación
en desarrollo web en TripleTen.

El objetivo es presentar mis habilidades,
herramientas y proyectos mientras continúo
aprendiendo desarrollo web.

## Tecnologías utilizadas

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Metodología BEM
- Diseño responsive
- Git y GitHub

## Características

- Presentación personal
- Sección de habilidades y herramientas
- Proyectos destacados
- Sección de contacto
- Diseño adaptable a diferentes dispositivos
